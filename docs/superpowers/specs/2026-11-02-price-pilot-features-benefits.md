# Price Pilot: features, benefits, and rollout ideas

Date: 2 November 2026
Language: NZ English. No em dashes.
Status: Working draft from Guy Hollister

## Tier gate

- **50 km Local:** core cockpit, fence compare, advise + export.
- **100 km system:** only tier that unlocks the premium modules below (Forecast Pack, Loss-leader lab, Price → Sales, Supplier Pack, full store scorecard).
- Login is hard-bound to the store address. Radius cannot be edited.

## Core (50 km and up)

| Feature | What it does | Benefit |
| --- | --- | --- |
| Nightly sync | Pulls prices + product list via generic kit | Always current without retyping |
| Rules engine | Brand, item, product, category, seasonal, keyword, custom tag | Clean pricing under their rules |
| Advise cockpit | Flags lines vs national Shelf Audit data | Catch overpriced lines before shoppers do |
| Clean export | Download recommended prices | Apply by hand until write-back |
| Fence compare | Every supermarket in locked radius | Look over the fence without sharing logins |
| Geo lock | Seat bound to store address | Stops password sharing across NZ |
| Multi-store compare | Side by side when each store is licensed | Fair multi-store owners, no copy-paste cheat |
| Suburb Summary | Rank inside 50 km fence; week-by-week graph across the year | See local league position move over time |

## Premium (100 km system only)

| Feature | What it does | Benefit |
| --- | --- | --- |
| Store scorecard feed | Hundreds of metrics for that store only | Keeps them in the loop nightly |
| National index for this store | Weekly rank vs NZ median | Honest national compare without a National key |
| Brand / category heat map | Over vs under national by brand and aisle | See where margin or trust is leaking |
| Uptick alerts | Ping when a fence competitor moves a key line | React before the week is lost |
| Private-label tracker | Pams / Homebrand / Signature vs peers | Protect own brands |
| Promo leak check | Specials that stayed high after the week | Stop silent upticks |
| Wage hit report | Basket vs local median wages | Tangible shopper impact story |
| Supplier Pack | Full supplier info system inside 100 km | Brands, SA-SUP IDs, price moves, aisle share |
| Forecast Pack | WoW projections, MoM, vs same week 12 months earlier | Plan cuts and rises with history |
| Loss-leader lab | Test milk, bread, or any product price drop | Preview volume and margin risk before going live |
| Price → Sales module | Elasticity, cross-effects, promo vs everyday, stock, competitor lag, footfall vs basket, rebates, season/weather, trust lag, brand cannibalisation | Move price with eyes open on sales effect |
| POS + accounting + remote delivery | Later upgrade: push clean prices into store systems | Close the loop without CSV |

## Price → Sales checklist (inside premium)

1. Elasticity by SKU
2. Cross-effects (cheap milk lifts bread, kills own brand)
3. Promo vs everyday
4. Stock / out-of-stock noise
5. Competitor reaction lag inside the fence
6. Footfall vs basket
7. Supplier deal / rebate true cost
8. Season and weather
9. Trust lag (cuts noticed slower than rises)
10. Cannibalisation inside a brand family

## Rollout order (ideas)

1. Core cockpit + 50 km fence + geo lock
2. 100 km seat unlocks premium modules
3. Supplier Pack + scorecard feed
4. Forecast Pack + Loss-leader lab
5. Price → Sales module
6. Named POS / accounting write-back and remote pricing delivery

## Pricing notes (locked so far)

- Local 50 km: $1,150 / month + GST
- Local 100 km: $1,600 / month + GST ($1,150 + $450)
- Annual: 35% off list
- Chain NZ buy-in: 25% off list, all stores, each store gets its own login
- National list and seat package prices still open
